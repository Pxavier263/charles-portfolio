# Update pack: 3 October 2026

This pack holds every file changed since the first version you put on GitHub (2 October). It covers both updates from today, so it works whether or not you copied the earlier floating-hero pack.

## What's new

1. **New colour theme: Deep Teal + Burnt Orange**

   | Role | Colour |
   |---|---|
   | Primary (headings, navigation, links, dark sections) | Deep Teal `#0F4C5C` |
   | Accent (buttons, highlights) | Burnt Orange `#E36414` |
   | Background | `#F7F9F9` |
   | Body text | `#1B2A2F` |

   Buttons with white text use `#C2530F`, one shade deeper than `#E36414`, so the text meets the WCAG AA contrast standard. The full palette is in `tailwind.config.ts` and `app/globals.css`.
2. **No em dashes.** All visible text was rewritten with commas, colons, full stops or brackets. The launch check now warns you if one slips back into your content.
3. **New share image.** `public/og.png`, the preview on LinkedIn and WhatsApp, is redrawn in the new colours.
4. **From the earlier pack:**
   - The floating-label hero.
   - The tablet header fix.
   - The Windows-safe checks.
   - Clearer guides.

## Before you copy: the `data/` files

This pack includes 12 files from `data/`, because their wording changed:

```
achievements.ts  conversion.ts  education.ts  experience.ts  footprint.ts  gallery.ts
photos.ts  presentations.ts  projects.ts  services.ts  stories.ts  taxonomy.ts
```

- **If you have NOT edited a file since uploading:** let it be replaced.
- **If you HAVE edited a file** (e.g. added photo paths to `gallery.ts` or `photos.ts`): don't copy that file. Keep yours. The site still works, and the launch check on GitHub (Actions → latest run → Summary) lists any em dashes left in it, quoting the words to search for, so you can fix them by hand.

`data/profile.ts` is deliberately **not** included, so your name, email, links and settings stay as they are.

## Optional: the floating cut-out photo

Add this line to `data/profile.ts`, just below the `headshot:` line:

```ts
  heroPortrait: null as string | null,
```

When you have a photo with its background removed, save it as `public/images/hero-portrait.png` and change `null` to `"/images/hero-portrait.png"`.

You can delete this file after updating. It does not affect the site.
